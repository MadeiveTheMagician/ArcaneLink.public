# ArcaneLink

ArcaneLink is a centralized communication platform for communities.

This public repository makes the source visible for academic review. It is
**source-available, not open source**. Public visibility or technical access
does not itself constitute authorization or grant permission; only reviewers
explicitly authorized by the copyright holder receive the limited rights in
the [ArcaneLink Academic Review License](LICENSE).
