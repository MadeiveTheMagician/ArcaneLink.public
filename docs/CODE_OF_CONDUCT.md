# Code of conduct

Project discussion and review must remain professional, specific and safe.

- Treat contributors and reviewers with respect.
- Critique code and decisions, not people.
- Do not publish personal information, credentials or private user content.
- Do not use the project channels for harassment, discrimination or threats.
- Report security issues privately and allow reasonable time for remediation.
- Respect the repository license and the boundaries of academic access.

The repository owner may restrict participation or remove content that violates
these expectations.
