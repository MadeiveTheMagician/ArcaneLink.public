# ArcaneLink

**Версия-кандидат:** `1.0.0-rc.1`  
**Официальный сайт:** [arcane-link.ru](https://arcane-link.ru)  
**Статус репозитория:** закрытый исходный код для академической проверки

[English version](README.md)

ArcaneLink — централизованная коммуникационная платформа для сообществ. Она
объединяет серверы и спейсы, личные и групповые чаты, файлы, реакции,
модерацию, детальные права ролей, голосовую связь, видео и демонстрацию экрана.

Это не демонстрационная выгрузка, а разворачиваемый monorepo релиз-кандидата:
backend на ASP.NET Core, миграции PostgreSQL, web-клиент React, оболочки desktop
и Android, инфраструктура, автоматические тесты и эксплуатационная
документация. Пользовательские данные, рабочие ключи, секреты, подписи и
артефакты локальной среды в репозиторий не входят.

## Структура

```text
backend/
  ArcaneLink/          API, SignalR и миграции EF Core
  ArcaneLink.Tests/    модульные и интеграционные тесты
  tools/               вспомогательные backend-инструменты
frontend/
  client.web/          приложение React и TypeScript
  client.desktop/      оболочка Electron
  client.mobile/       оболочка Capacitor Android
infrastructure/
  nginx/               конфигурация обратного прокси
  scripts/             развёртывание и эксплуатация
docs/                  документация проекта
```

## Что реализовано

- Аккаунты, сессии, профили, друзья, личные и групповые чаты.
- Серверы сообществ, категории, текстовые и голосовые спейсы, связанные чаты.
- Сообщения, ответы, редактирование, реакции, упоминания, вложения, закрепления,
  поиск и состояние прочтения.
- Голосовые комнаты, камера и демонстрация экрана с сигналингом через SignalR,
  соединениями WebRTC и поддержкой STUN/TURN.
- Роли, гранулярные права, защищённые ресурсы, модерация, приглашения, заявки,
  блокировки и аудит.
- Политика хранения файлов, health endpoints, структурные логи и проверенная
  цепочка миграций PostgreSQL.

1. [Разработка](DEVELOPMENT.md) — зависимости и локальный запуск.
2. [Конфигурация](CONFIGURATION.md) — переменные окружения и секреты.

Краткий контейнерный сценарий:

```text
copy .env.local.example .env
docker compose up -d --build --wait
```

Перед запуском необходимо заменить две заглушки секретов. Сервис миграций
запустится до backend. Для официального TLS-окружения и обновления постоянной
БД используйте подробное руководство по развёртыванию.

## Архитектурная граница

ArcaneLink остаётся единым централизованным сервисом: backend является
источником истины для учётных записей, прав, сообщений, хранимых данных и
сигналинга. В официальной конфигурации WebRTC идёт только через TURN с
краткосрочными доступами, которые выдаёт backend; прямое соединение разрешено
только при локальной разработке. В версии `1.0.0-rc.1` нет SFU, поэтому backend
не микширует и не анализирует медиапотоки.
Референсная конфигурация рассчитана на один backend и одну PostgreSQL; высокая
доступность нескольких узлов пока не заявляется.
